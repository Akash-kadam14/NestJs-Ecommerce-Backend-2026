1. setup project using nest js cli
2. install prisma at root level prisma/schema.prisma file and generate prisma client and model using prisma schema file
3. install pg, @prisma/client, prisma-adapter-pg in src/prisma folder and create prisma service as wrapper for the user and other modules
4. run the command npx prisma generate client create the prisma client then after ran npx prisma migrate dev --name <migration-name>  to create the coulmns directly in postgres db from the schema
5. prisma service lifecycle , when we start app db conncetion should be established and close when app shuts down. we use OnModuleInit and onModuleDestroy
6. we add Prisma module gloabally so all modules can access install
7. we create a user dto with validation using class-validator and class-transformer
8. create a user/createUser route in controller and test the DTO validation  
9. started create a login route in auth controller and create a loginDto
10. implement authentication using bcrypt and jwt token
11. create a UserSession schema for multiple device login and migrate it using prisma migrate dev 
12. on user login generate and store both access token and refresh token
13. Implement the Authentication using JWT Guard and jwt passport strategy. Install packages like @nestjs/passport "passport" "passport-jwt" "@nestjs/jwt"
14. create jwt stratgey by using passport startegy and create jwtAuth guard which extends AuthGuard so internally it valdiate the token and return payload by attaching req.user in it
15. test the authentication usin @UseGuard(JwtGuard) on getProfile route.
16. Create a super admin user via prisma seed file create file under prisma folder. then add the command tsx prisma/seed.ts in prisma.config.ts file
17 install tsx as dev deps tsx helps to run ts file in node enviroment.
18. use npx prisma db seed command to run the seed file this command is configured with the prisma itself, so instead creating normal npm script we prefer prisma script
19. create logout from one and all device routes 
20. implement access and refresh token api
21. delete current device/browser from userSession table on logout from one device api and delete all sesison from logout all device api
22. Install @nestjs/schedule and imported in app module as schedule.forRoot() to run the cronjob for remove expired sessions from userSession table
