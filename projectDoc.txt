27. @Type(() => CreateProductDTO) (from class-transformer)
Purpose: Transformation / Deserialization
What it does: It takes each plain JavaScript {} object inside the array and converts (instantiates) it into a real TypeScript class instance of CreateProductDTO.
Why it's needed: Without this, the items remain plain objects, and class-validator cannot read the decorator metadata (@IsString(), @IsNumber(), etc.) defined on the CreateProductDTO class.

28. @ValidateNested(): Tells class-validator not to stop at the top level, but to go inside the nested object and execute all of its validation rules.
{ each: true }: Tells class-validator that this property is an array, so it must loop through every single item in the array and validate each one individually.
